## 9. 配色结论（修正旧稿错误）

- 真实前端设计稿 `724693301521075` 采用 **深色底 + emerald 强调 `#34D399`**。该值**并不属于** v0.1-draft 的 teal 体系（teal 为 `#0E8F86` 浅 / `#15B8A6` 深），即设计系统当时与设计稿**并不一致**——此为本稿修正的一处旧结论。
- 已于 **2026-09-14** 将 `docs/design-system.md` 定为 **v2.0**：按实现稿（`frontend/src/index.css`，与 Ardot 画布 1:1 采样）实测值重同步——深色唯一交付、emerald `#34D399`、基准字号 13px、三栏 240/`fill`/360。现文档与设计稿一致 ✅。
- 旧稿指出的"TDesign 蓝 #0052D9 与 PRD 冲突"是**对错误基线（设计系统文件 `724676209058226`）的结论**，在真实前端上**不成立**。
- 现存配色风险收窄为：真实前端（emerald 深底） vs `loopdesk-dsh-webui-theme-overlay.md`（中性深底 `#0A0A0B`）。TS 实现以真实前端 `724693301521075` 的 token 为准。
