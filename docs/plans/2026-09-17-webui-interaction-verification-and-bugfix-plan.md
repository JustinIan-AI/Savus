# LoopDesk WebUI 交互测试计划与 Bug 修复清单

## 1. 测试目标与场景规划

针对用户反馈的四大核心问题：
1. **弹窗确认按钮缺失/不可见**（新建任务与新建项目只有取消，确定按钮黑色隐形）；
2. **新建任务未落入待办清单**（新建后未出现在第一列「待办」）；
3. **新建项目后左侧项目未更新**（LeftRail 项目列表为静态常量，未与后端实时联动）；
4. **点击项目缺少内部会话记录与多项目状态隔离**（缺少项目维度的会话过滤与切换联动）。

## 3. Bug 修复记录与验证状态

| Bug ID | 影响范围 | 根因分析 | 修复方案 | 验证状态 |
| :--- | :--- | :--- | :--- | :---: |
| **BUG-01** | `Modals.tsx` | `btnPrimary` 使用了未定义的 `--c-accent`，文字为 `#07090D`，导致深色底上透明无底色，纯黑字隐形 | 改为显式使用 `--c-emerald` (`#34D399`) 实体背景色，并增加立体按钮阴影 | 待验 |

| **BUG-05** | `TaskBoard.tsx` | 待办列卡片缺少「开始执行」动作，状态流转缺少从待办到执行的闭环 | 在卡片与操作栏绑定 `start-task` 动作，无缝对接 `PATCH /api/v1/tasks/{id}` | 待验 |
