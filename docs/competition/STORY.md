# GOAI Agent Infra 初赛 PPT · 叙事逻辑

## 核心命题
AI Agent 的研发交付是"自报告"的——它说完成了，却没人能证明。LoopDesk 作为 AgentTeams 的第四种 Worker Runtime，用**独立验证 + 证据留痕 + 人工门禁 + 经验蒸馏**补齐官方声明不做的运行时可靠性层，让交付从"自己说完成"变成"被独立验证过"。

## 叙事弧线（19 页）
1. 封面：项目名 + 一句话定位
2. P0 一页纸：名称/定位/问题/方案/创新/价值/进展 六事实
3. 目录：八章导览
4–5. 第一章 场景与价值（25%）：核心洞察"自报告不可信" + 5 大痛点对应八步闭环后四步
6–7. 第二章 方案总览：分层架构（用户→AgentTeams→LoopDesk Runtime→内核→MCP/阿里云Skills→存储）+ 选型必要性
8–9. 第三章 多Agent协同（25%）：4 职能 Agent + 1 人类，Verifier 三重工程强制，八步闭环对应
10–11. 第四章 Skill工程体系（25%·必选）：三层（阿里云官方/已有62/新建7）+ 兼容性零适配
12–13. 第五章 工程落地安全可审计（20%）：可观测/安全治理/运行验证（自举回归集+Badcase）
14–15. 第六章 开源计划（5%）：范围/协议/依赖披露/迁移成本
16–17. 第七章 落地计划进展：已实现 + 复赛里程碑 M1–M4 + 风险控制
18–19. 第八章 团队介绍：占位待填

## 评分权重映射
- 场景价值 25% → 第一章
- 多Agent协同 25% → 第三章
- Skill工程 25% → 第四章
- 工程落地安全可审计 20% → 第五章
- 开源 5% → 第六章
- 事实边界（红线）→ 全程 [已实现]/[增强]/[新建] 标注
